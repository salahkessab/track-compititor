# Writing models and reference photographs

Recipe Intelligence supports GPT-5.4 Mini and GPT-5.5 in its writing-model selector. Existing batches retain their saved model. New quotes, spending reservations and usage reconciliation use the selected model's own prices, including cached input and GPT-5.5's long-context threshold. The free access check fetches model metadata; only an approved production request can confirm generation compatibility.

Standard GPT-5.5 pricing was checked on 2026-11-10: $5 per million input tokens, $0.50 cached input and $30 output. Above 272,000 input tokens, the input multiplier is 2 and the output multiplier is 1.5. The existing structured article schema and `reasoning.effort: none` remain supported. See the [official GPT-5.5 model page](https://developers.openai.com/api/docs/models/gpt-5.5).

The provider also supports an explicit reference edit payload: one to five PNG, JPEG or WebP data URLs are sent as actual multipart files to `/v1/images/edits`. Invalid references fail locally. No automatic retry or model substitution is added. The `recipe-reference-photo-v1` prompt preserves the visible meal and cooking stage, asks for small changes to tableware and angle, and binds ingredient paper labels to an explicitly supplied ingredient inventory. Reference edits retain the chosen dimensions without a portrait-crop instruction.

These helpers prepare the supervised Marry Me Chicken Pasta reference-gallery test.
